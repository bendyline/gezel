# AMD ROCm SDK 10.0.0 (TheRock), as the llama-cpp ROCm legs of
# .github/workflows/build-native.yml install it:
#
#   pip install --require-hashes --no-deps --no-build-isolation \
#     --index-url https://stable.repo.amd.com/rocm/whl-next/ \
#     -r native/scripts/rocm-sdk-requirements.txt
#   rocm-sdk init
#
# Every file is pinned by sha256 for both platforms (linux_x86_64 and
# win_amd64), so nothing unpinned enters a native build. `rocm` is a source
# archive whose `rocm-sdk init` expands the devel tree; it builds with the
# setuptools pinned in rocm-sdk-build-requirements.txt, installed first.
#
# One `rocm-sdk-device-<gfx>` wheel per architecture the ROCm build targets:
# they carry the rocBLAS kernels the variant bundles. The list must equal
# ROCM_GFX_TARGETS (packages/core/src/native/rocm-devices.ts) and the
# workflow's rocm_gpu_targets; scripts/native-payload.test.mjs holds them
# together.
#
# Bumping ROCm: change every version here, recompute each hash from the file
# itself (AMD's index publishes none), rebuild, and re-measure against the
# Vulkan build before shipping.
