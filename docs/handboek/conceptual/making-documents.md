# Making and converting documents

Your crew can hand you real files, not just text in a chat. Ask for a Word document, a PowerPoint deck, an Excel spreadsheet, or a PDF, and that's what you get back: a file you can open, send, and print.

## What you can ask for

Say what you want and which format, in your own words:

- "Turn my meeting notes into a Word document."
- "Convert the JSON files here to DOCX files."
- "Make a PowerPoint from this outline."
- "Export these tables as an Excel spreadsheet."
- "Bring `quarterly-review.md` in line with the look of `brand.pptx`."

Naming the format ("as a Word document", "to .docx") or a file ("report.docx") is what tells your gezel this is document work, so it's worth saying.

## How it works

Gezel ships with **DocBlocks**, a document converter that runs on your own computer. When a request calls for a document, the gezel working on it gets DocBlocks' tools for that conversation. It can write Word (`.docx`), PowerPoint (`.pptx`), Excel (`.xlsx`), PDF, CSV, web pages, and ebooks (`.epub`), and turn a deck into an animated slideshow (MP4 or GIF) or images.

It works from Markdown, from Word, PowerPoint, and Excel files, and from files your crew already made. Data that isn't a document yet, such as JSON or a log, gets laid out as a readable document first and then converted, one file at a time or all together, whichever you asked for.

Your crew can read documents too. Add Word, PowerPoint, Excel, or PDF files to a project and your crew can read them as text, to summarize, compare, or answer questions about them.

## Where the files go

Finished files land in the project's **artifacts**, listed in its Artifacts tab, next to everything else your crew makes (see [Projects, threads, and where work lives](projects-and-threads.md)). Converting never changes the files you started from, and a folder you've added read-only is never written to.

## Bigger documents

For a deck or report that needs research, an outline, and a review before it's done, use a craftbook. **PowerPoint from Content**, **Word Document from Content or Research**, and **Formatted Report** each plan the document, write it, check it, and save the file. Ask the Meester for "a PowerPoint about…" and they'll start the right one; [Craftbooks](craftbooks-overview.md) explains how they run.

## If a gezel says it can't

Small models on your own computer sometimes overlook a tool they have. If a gezel says it can't make a document, ask again and name the format and the files plainly: "Convert the JSON files in this folder to .docx files."
