# Views: see what's in a folder

Once gezel has read a folder you added, the project's **Views** tab shows what
it found. The tab is named after the view you last chose ("Gallery view").
Click it again to pick another. Every view comes from gezel's index of the
folder, so nothing is opened or changed to draw it.

## The views

- **Village** shows a codebase as a small town you come to know: each file is
  a building, and the streets are the files that use each other.
- **Guide** says what each folder is for and which files the rest of the
  project leans on.
- **Diagram** draws files as boxes and arrows, from each file to the ones it
  uses. Folders open and close, and double-clicking a file shows just that
  file and its neighbors.
- **Reports** lists everything gezel has written about the project, such as
  the overnight reports, the codebase map and code reviews, and lets you read
  them in place. **Write … now** writes one straight away, so you don't have
  to wait for the night.
- **Gallery** puts the files on shelves: by type (photos, slides,
  spreadsheets, notes), by folder, or, for a photo folder, by outing. A photo
  folder starts with its **Exact copies** and **Look-alikes**. You can narrow
  it to photos, documents, data, media or code, or type a word to find files
  that mention it.
- **Timeline** shows what changed when, as bars by week, month or year. For a
  codebase, the bars count its commits, colored by part of the project. For any
  other folder, each file sits at its own date, and a photo at the time it was
  taken. Choose a bar to see what happened in that stretch.

Not every view suits every folder: a Pictures folder has no Guide or Diagram,
for instance. A new project opens on the view that suits it: the Village for
code, and the Gallery for pictures and documents.

## One file, the same everywhere

Choosing a file in any view opens it in the panel on the right. The panel
says what the file is and what gezel's summary says about it. It also shows
what the file uses and what uses it, any problems the
[Librarian](the-crew.md) found, and a preview. The file stays chosen when
you switch views, so you can find it in the Diagram, then see when it last
changed on the Timeline.

The views are drawn from the same index the [Night Shift](night-shift.md)
keeps up to date, so a folder you [added](adding-folders.md) yesterday fills
in by morning.
