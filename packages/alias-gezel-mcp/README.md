# gezel-mcp

Gezel's MCP server, `gezel-mcp`, under its short name. It installs
[`@bendyline/gezel-mcp`](https://www.npmjs.com/package/@bendyline/gezel-mcp)
and runs its `gezel-mcp` command, so the two are the same program.

To use Gezel's tools in Claude Code, Codex, Cursor, Claude Desktop or VS Code,
let Gezel set that up: Settings → Integrations in the desktop app, or the
`gezel mcp` command. Either one writes the entry each app needs.

Gezel needs Node.js 24 or newer. See the
[command-line reference](https://gezel.com/docs/cli-reference/).
