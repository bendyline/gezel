# gezel-cli

Another name for the Gezel command line,
[`@bendyline/gezel-cli`](https://www.npmjs.com/package/@bendyline/gezel-cli).
It installs that package and runs its `gezel` command.

The short way to run it is the `gezel` package:

```bash
npx gezel
```

Gezel needs Node.js 24 or newer. Install one of `gezel`, `gezel-cli` or
`@bendyline/gezel-cli` globally, not more than one: they all provide the same
`gezel` command.

See the [command-line reference](https://gezel.com/docs/cli-reference/).
